Honest notes — read these before anyone sells you “one-click AI”

Ultra-level results come from a stack, not a slogan. Here is exactly where the open-source world stands, as checked by us.

01

No single tool does it all

There is no open-source CapCut-style app that takes one prompt and returns a finished, premium edit end-to-end. The stack on this page — planner, matting, FFmpeg, Whisper, editors — is how it is really done.

02

Browser power has a ceiling

In-browser editing via ffmpeg.wasm is real and useful, but the input caps around 2 GB and it runs noticeably slower than native FFmpeg. Big projects go to the desktop or server tier — we say so in every plan.

03

Some licences are not commercial

Code licences and AI model weights are separate things. ProPainter's weights are non-commercial only, and the same applies to F5-TTS and XTTS voice weights — so none of them are used in paid client work here, ever.

04

Urdu captions get a human pass

Whisper transcribes Urdu well, not perfectly. Every Urdu subtitle file that leaves this studio is read and corrected by a person before it is burned in.

05

GPU work is measured in minutes

AI restyling and object removal run on RTX-class GPU servers and take minutes per clip, not seconds. Any service promising instant generative edits in a browser tab is showing you a demo, not a workflow.

06

Checked, dated, re-checked

Every licence on this page was checked against official licence pages on 26 October 2026 — and model weights can carry separate terms from code licences. Open-source projects change — when a licence changes, this page changes with it.
